# NovelCast Backend

This directory is reserved for backend services, APIs, and proxy handlers.

## Planned Capabilities
- **Text-to-Speech (TTS) Proxy**: Secure integration with Fish Audio API for real-time voice narration streaming.
- **User Accounts & Sync**: Synchronize reading progress, bookmarks, and custom shelves across devices.
- **Audio Cache**: Cache synthesized audio chunks for faster playback and lower API consumption.
